# Roadmap

Direction, not a promise. Items move or disappear as evidence arrives. Each
item links to an issue once work starts.

## Now

- Green CI on `main`, protected branch, release automation
- Docs site published from `docs/`
- First tagged release after the automation lands

## Next

- Supply-chain hardening: artifact attestations on release assets
- Semantic symbol index maturity (pgvector path)
- Onboarding polish: fewer steps between install and first review

## Later

- Dashboard rebuild on a token-based design system
- Versioned documentation, once a second release line exists
- Additional forges, only if demand is demonstrated

## Not planned

- Hosted SaaS offering
- Splitting the backend, dashboard and docs into separate repositories
